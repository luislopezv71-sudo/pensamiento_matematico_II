1. Conceptos esenciales

Los números reales (ℝ) permiten representar posiciones en una recta numérica continua: incluyen números racionales y números irracionales. Para este curso tomaremos ℕ = {1, 2, 3, …}; algunos textos también incluyen el 0.

Naturales (ℕ)
1, 2, 3, …; sirven para contar.
Enteros (ℤ)
…, −3, −2, −1, 0, 1, 2, …; incorporan negativos y cero.
Racionales (ℚ)
Se expresan como a/b, con a y b enteros y b ≠ 0. Su decimal termina o es periódico: 0.25 = 1/4; 0.333… = 1/3.
Irracionales (ℝ∖ℚ)
No pueden escribirse como cociente de dos enteros. Su desarrollo decimal es infinito y no periódico: √2, π.
Reales (ℝ)
La unión de racionales e irracionales. Todo natural es entero, todo entero es racional y todo racional es real.
ℕ ⊂ ℤ ⊂ ℚ ⊂ ℝ   y   ℝ = ℚ ∪ (ℝ∖ℚ)
Evita este error: √9 = 3 es racional y natural; no todas las raíces cuadradas son irracionales. 0 es entero y racional, pero no natural bajo la convención elegida aquí.

2. Propiedades que utilizamos

Conmutativa

a + b = b + a y ab = ba.

Ejemplo: −3 + 8 = 8 + (−3) = 5.

Asociativa

(a + b) + c = a + (b + c).

Ejemplo: (2 + 3) + 4 = 2 + (3 + 4).

Distributiva

a(b + c) = ab + ac.

Ejemplo: 3(4 + 2) = 12 + 6.

Inversos y elementos neutros

a + 0 = a; a × 1 = a. El inverso aditivo de 5 es −5. El inverso multiplicativo de 5 es 1/5.

Estas propiedades se aplican a sumas y multiplicaciones de reales. La división entre cero no está definida.

Compara y ordena

En la recta numérica, los números mayores aparecen a la derecha. Por ejemplo, −2 < −0.5 < 0 < 1/2 < √2.

Ejemplos resueltos paso a paso

Ejemplo 1. Clasificar −6

  1. Es negativo: no pertenece a ℕ.
  2. Es entero: −6 ∈ ℤ.
  3. Puede escribirse −6/1: pertenece a ℚ.
  4. Por lo tanto, también pertenece a ℝ.
Conjunto más específico: enteros.

Ejemplo 2. Convertir 0.75 en fracción

  1. 0.75 = 75/100.
  2. Divide numerador y denominador entre 25.
  3. 75/100 = 3/4.
  4. Como es un cociente de enteros con denominador distinto de cero, es racional.

Ejemplo 3. Comparar −3/2 y −1.2

  1. −3/2 = −1.5.
  2. En la recta, −1.5 queda a la izquierda de −1.2.
  3. Concluimos −3/2 < −1.2.

Ejemplo 4. Reconocer una raíz exacta

  1. √49 = 7 porque 7 × 7 = 49.
  2. 7 es natural, entero, racional y real.
  3. En cambio √2 no se expresa como fracción exacta de enteros: es irracional.

Ejemplo 5. Propiedad distributiva en una compra

  1. Cuatro paquetes incluyen un cuaderno de $25 y un lápiz de $5.
  2. Costo = 4(25 + 5).
  3. Distributiva: 4 × 25 + 4 × 5 = 100 + 20.
  4. Total: $120.

Ejemplo 6. Temperatura y cambio

  1. Una temperatura de −4 °C aumenta 7 °C.
  2. Representamos −4 + 7.
  3. Resultado = 3 °C: un número entero y real.
