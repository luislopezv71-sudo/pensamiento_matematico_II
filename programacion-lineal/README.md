# Progresión 14 — Optimización y programación lineal

**Universidad William Osler · Bachillerato · Zihuatanejo, Guerrero · 2026**  
**Catedrático:** L.I. Luis Arturo López Vergara

## Propósito
Interpretar un problema de uso eficiente de recursos mediante una función objetivo y restricciones lineales, construir la región factible y evaluar sus vértices para encontrar un máximo.

## Secuencia
1. Definiciones: variables, restricciones, región factible y función objetivo.
2. Seis ejemplos resueltos de modelación, intersección, evaluación y decisión.
3. Laboratorio SVG de programación lineal 2D con tres restricciones ax+by≤c, x≥0, y≥0, tablas de vértices y máximo.
4. Seis ejercicios autocorregibles (30 puntos).
5. Cuaderno: definiciones (5), ejemplos resueltos (5), cinco ejercicios (10), reflexión (5).
6. Tres retos (15) y dos interpretaciones (10).
7. Resultados y seguimiento: teoría (20), ejercicios (30), retos (15), interpretación (10); cuaderno 25 puntos potenciales sujetos a validación presencial.

## Alcance
El laboratorio usa variables reales no negativas, coeficientes no negativos y restricciones de máximo. No realiza minimización arbitraria ni programación entera; el ejemplo de minimización se explica por escrito. Las soluciones decimales se deben interpretar considerando la naturaleza divisible o indivisible de los bienes. Si falta una cota finita del eje x o del eje y, el simulador pide establecerla.
