1. Conceptos fundamentales

Plano cartesiano
Sistema de referencia formado por dos ejes perpendiculares que se cruzan en el origen (0,0).
Par ordenado (x,y)
x indica desplazamiento horizontal y y vertical: el orden sí importa.
Cuadrantes
I (+,+), II (−,+), III (−,−), IV (+,−). Los puntos situados sobre ejes no pertenecen a ningún cuadrante.
Distancia entre dos puntos
Longitud del segmento de extremos A(x₁,y₁), B(x₂,y₂). Resulta del teorema de Pitágoras.
Punto medio
Punto que divide el segmento en dos partes de igual longitud.
Perímetro y área
Perímetro: suma de lados, en unidades lineales. Área: medida de superficie, en unidades cuadradas.
Área por coordenadas (zapatero)
Para un polígono simple con vértices en orden, el área es la mitad del valor absoluto de la diferencia de las sumas cruzadas.
d = √[(x₂−x₁)² + (y₂−y₁)²]   ·   M = ((x₁+x₂)/2, (y₁+y₂)/2)
Área = ½ |Σ(xᵢ yᵢ₊₁ − yᵢ xᵢ₊₁)|
La fórmula del área funciona con vértices consecutivos de un polígono simple (sin cruces). En el laboratorio se ofrecen triángulos y cuadriláteros sencillos para garantizarlo.

2. Ejemplos resueltos paso a paso

Ejemplo 1. Distancia entre A(−2,3) y B(4,−5)

  1. Δx = 4−(−2) = 6 y Δy = −5−3 = −8.
  2. d = √(6²+(−8)²) = √(36+64) = √100.
  3. Resultado: 10 unidades.

Ejemplo 2. Punto medio entre A(−6,4) y B(2,−2)

  1. Mₓ = (−6+2)/2 = −2.
  2. Mᵧ = (4−2)/2 = 1.
  3. Resultado: M(−2,1).

Ejemplo 3. Área de un rectángulo con negativos

  1. Vértices A(−4,−2), B(2,−2), C(2,3), D(−4,3).
  2. Base = 2−(−4) = 6; altura = 3−(−2) = 5.
  3. Área = 6×5 = 30 u².

Ejemplo 4. Área de un triángulo rectángulo

  1. Vértices A(−3,−2), B(3,−2), C(−3,2).
  2. Base horizontal = 6 y altura vertical = 4.
  3. Área = (6×4)/2 = 12 u².

Ejemplo 5. Área con coordenadas (método del zapatero)

  1. Polígono A(−2,−1), B(3,−1), C(3,2), D(−2,2).
  2. Σ(xᵢyᵢ₊₁) = 2+6+6+2 = 16; Σ(yᵢxᵢ₊₁) = −3−3−4−4 = −14.
  3. Área = |16−(−14)|/2 = 15 u², igual a base 5 por altura 3.

Ejemplo 6. Terreno triangular en Zihuatanejo

  1. Un terreno tiene vértices P(−4,−3), Q(4,−3), R(0,3); una unidad equivale a 1 metro.
  2. Base PQ = 8 m; altura respecto a PQ = 6 m.
  3. Área = (8×6)/2 = 24 m².

C. Cinco ejercicios manuscritos (10 puntos)

  1. Grafica A(−5,4) y B(3,−2). Calcula distancia y punto medio.
  2. Dibuja el triángulo P(−4,−2), Q(2,−2), R(−4,3). Calcula sus tres lados, perímetro y área.
  3. Dibuja el rectángulo con vértices (−3,−3), (4,−3), (4,2), (−3,2). Calcula el área por base×altura y por fórmula de coordenadas.
  4. Traza el trapecio (−5,−2), (5,−2), (2,3), (−5,3). Obtén área por fórmula del trapecio y método del zapatero.
