# Progresión 11 — Plano cartesiano, distancias y áreas

**Universidad William Osler · Bachillerato · Zihuatanejo, Guerrero · 2026**  
**Catedrático:** L.I. Luis Arturo López Vergara

## Objetivo
Utilizar un sistema de coordenadas, distancia entre dos puntos y métodos geométricos para calcular perímetros y áreas de polígonos simples, y comparar resultados mediante coordenadas y fórmulas de geometría básica.

## Etapas
1. Conceptos y teoría, con cuestionario de 20 puntos.
2. Seis ejemplos desarrollados.
3. Laboratorio SVG con cuatro escenarios, puntos negativos y positivos, mediciones y comparación de áreas.
4. Seis ejercicios autocorregibles, 30 puntos.
5. Cuaderno obligatorio de 25 puntos, pendientes de validación docente.
6. Tres retos (15 puntos) y dos interpretaciones (10 puntos).
7. Resultados y guardado local del progreso.

**Puntuación:** 75 digitales, 25 de cuaderno declarado por el alumno, no acreditado automáticamente.

## Método de las áreas
El método analítico utiliza la fórmula del zapatero para polígonos simples cuyos vértices están dados en orden de contorno. La comparación geométrica se realiza con las figuras preestablecidas. Al modificar vértices, la aplicación muestra el área analítica y aclara cuándo ya no es válida la fórmula geométrica original.

## Tecnologías
HTML5, CSS3, JavaScript, SVG y `localStorage` sin cuentas ni conexión a servidores externos.
