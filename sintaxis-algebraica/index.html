1. ¿Qué es la sintaxis algebraica?

La sintaxis algebraica es el conjunto de reglas para escribir y operar expresiones de manera correcta. Los símbolos y los paréntesis determinan cómo se interpretan las operaciones. Por ejemplo, 2(x + 3) significa duplicar toda la suma; en cambio, 2x + 3 significa duplicar solamente x y después agregar 3.

Expresión algebraica

Combinación de números, letras (variables) y operaciones. Ejemplo: 4x + 7.

Expresiones equivalentes

Producen el mismo valor para todos los valores permitidos de sus variables. Ejemplo: 3(x + 4) y 3x + 12.

Elementos de 5x² − 3x + 8

Variable
x representa un número cuyo valor puede cambiar.
Coeficientes
5 y −3 multiplican a la variable o a su potencia.
Exponente
El 2 en x² indica x multiplicada por sí misma.
Término independiente
8 no está multiplicado por ninguna variable.
Términos semejantes
Comparten las mismas variables elevadas a los mismos exponentes; por ejemplo 2x y 5x.

Cuatro formas útiles de una expresión

FormaEjemplo¿Para qué conviene?
Con paréntesis3(x + 4)Representa tres paquetes iguales.
Desarrollada3x + 12Permite identificar términos y sumar.
Simplificada5x + 7 (de 2x + 3x + 7)Reduce términos semejantes.
Factorizada4(x + 3) (de 4x + 12)Reconoce un factor común.

Reglas fundamentales

Distributiva: a(b + c) = ab + ac. Reducción: 2x + 5x = 7x. Factor común: 6x + 12 = 6(x + 2). Producto notable: (x + 3)² = x² + 6x + 9.

Atención: (x + 3)² no es x² + 9. El término central 6x también aparece al desarrollar el cuadrado.

2. Ejemplos completamente resueltos

Ejemplo 1. Paquetes de datos para videojuegos

Una empresa ofrece 3 paquetes, cada uno con x GB más 4 GB adicionales. ¿Cuántos GB hay en total?

Paso 1. Tres paquetes iguales: 3(x + 4).

Paso 2. Aplicamos distributiva: 3·x + 3·4.

Paso 3. Expresión desarrollada: 3x + 12.

Comprobación: si x = 2, 3(2 + 4) = 18 y 3(2) + 12 = 18.

Ejemplo 2. Venta de cuadernos

Se venden 2x cuadernos por la mañana y 5x por la tarde; además quedan 3 cuadernos de muestra.

Paso 1. 2x + 5x + 3.

Paso 2. 2x y 5x son semejantes; sumamos 2 + 5.

Resultado simplificado: 7x + 3. Si x = 4, ambas expresiones dan 31.

Ejemplo 3. Diseño de un terreno rectangular

La expresión del área es 4x + 12 metros cuadrados y un lado mide 4 metros. ¿Cuál es el otro?

Paso 1. Identificamos el factor común: 4.

Paso 2. 4x + 12 = 4(x + 3).

Resultado: el otro lado mide x + 3 metros, para valores de x que hagan positiva la longitud.

Ejemplo 4. Cuadrado de lado x + 2

Área = (x + 2)(x + 2).

Paso 1. x·x + x·2 + 2·x + 2·2.

Paso 2. x² + 2x + 2x + 4.

Resultado: x² + 4x + 4. Es un producto notable.
